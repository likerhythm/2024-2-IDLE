# 물류 자동화를 위한 로봇 FMS

## 개발 필요성
- 아마존, 알리익스프레스 등 글로벌 이커머스 기업이 로봇 FMS를 사용한 물류 자동화 기술을 선도하고 있습니다
- 이에 발맞춰 쿠팡, 마켓컬리 등 국내 이커머스 기업도 대규모 투자를 진행하고 있습니다
- 물류 로봇을 통제하는 국내 FMS 기술이 부족하여 중국 기술에 의존하고 있습니다

## 개발 목표
당일 배송과 일반 배송이 혼재하는 물류 창고 특성을 고려하여 작업을 효율적으로 처리하도록 작업을 할당하고 스케줄링하는 FMS를 개발하고자 합니다.
